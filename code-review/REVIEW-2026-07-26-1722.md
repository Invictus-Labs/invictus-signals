## Adjudicated Findings — requires team-lead/Knox decision

**`bbwp` naming (P1, Consistency Reviewer).** The finding is correct on its face — this is the one public function in the file that doesn't follow `calculate_*`. Not fixed here because:
1. The PRD's AC-5 names the function `bbwp` literally, not `calculate_bbwp`.
2. `bbwp`/BBWP is the actual, recognized name of the indicator being implemented (Bollinger Band Width Percentile) — `calculate_bbwp` would read as a made-up abbreviation of a term that already has a name.
3. It's already a live cross-repo contract: `invictus-bot` PR #144 (Risk Validator) is built and tested against this exact name, and that PR is explicitly sequenced to land *after* this one (board #2528). A rename now would require a coordinated re-sync on both sides.

A rationale comment was added directly above `bbwp()`'s definition so this reads as a documented, deliberate decision rather than an unexplained inconsistency. The author of this PR is also the one who chose the name, so this disposition is presented for team-lead/Knox to accept or override — not closed unilaterally.
